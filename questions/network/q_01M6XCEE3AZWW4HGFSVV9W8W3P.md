## 一句话
主机在 ARP 缓存里找不到目标 MAC 地址时，会在局域网广播询问“这个 IP 是谁”，目标主机单播回复自己的 MAC 地址。

## 要点
- [kp1|3] ARP 把同一局域网内的 IP 地址解析成 MAC 地址
- [kp2|3] 缓存里没有，就广播 ARP 请求，局域网内所有主机都会收到
- [kp3|2] 只有 IP 匹配的主机才单播回复自己的 MAC 地址
- [kp4|2] 发送方把结果写入 ARP 缓存，下次直接使用
- [kp5] 目标不在本网段时，解析的是网关的 MAC 地址

## 详解
### 先搞懂：办公室里喊一嗓子
你在办公室里要找小王，但不知道他坐在哪。你站起来喊：“谁是小王？”所有人都听到了，只有小王回答：“我在这。”你就记下了他的位置，下次直接过去。

ARP 就是这样。几个词：

- **MAC 地址**：网卡的硬件地址，在局域网内用来找到下一个设备。
- **ARP 缓存**：本机记录的“IP 对应哪个 MAC”的小表。
- **广播**：发给局域网内所有主机；**单播**：只发给一台主机。

### 为什么需要 ARP
数据在局域网里传，靠的是 MAC 地址。但应用只知道对方的 IP 地址。发送前，必须先知道这个 IP 对应的 MAC，ARP 就是干这件事的。

### ARP 的工作过程
假设主机 A 要给同网段的主机 B 发数据：

1. A 先查自己的 ARP 缓存，有 B 的记录，就直接用；
2. 没有，A 广播一个 ARP 请求，内容是“谁的 IP 是 B 的地址？请告诉我你的 MAC”，里面带着 A 自己的 IP 和 MAC；
3. 局域网里所有主机都收到请求，比较里面的目标 IP 和自己的 IP；
4. 只有 B 一致，B 就单播回复 ARP 应答，告诉 A 自己的 MAC；其他主机不理会；
5. A 收到应答，把 B 的 IP 和 MAC 写入缓存，然后发送数据。

### 目标不在本网段怎么办
ARP 只在同一个局域网内有效，广播不会被路由器转发出去。如果目标 IP 在别的网段，主机要解析的是默认网关的 MAC，把数据交给网关，由路由器继续转发。

### 为什么设缓存
如果每次发包都广播一次，局域网会很吵。缓存记录有存活时间，过期后会重新询问，这样地址变化时也能更新。

## 易错点
- 以为 ARP 应答也是广播；应答是单播给请求方
- 以为 ARP 能解析任意远处的 IP；它只在本局域网内起作用
- 以为缓存永远有效；记录会过期，之后重新询问

## 追问
### [f1] 访问另一个网段的服务器时，ARP 解析的是谁的 MAC？
是默认网关的 MAC。数据先发给网关，网关再按 IP 向外转发，每经过一段局域网都会重新做一次 ARP。
