## 一句话
多态需要三个前提：子类继承父类，子类重写父类的方法，并且用父类引用指向子类对象，三个缺一个都不行。

## 要点
- [kp1|3] 前提一：子类继承父类，或实现了接口
- [kp2|3] 前提二：子类重写了父类的方法
- [kp3|2] 前提三：父类引用指向子类对象，如 `Animal a = new Dog();`
- [kp4] 缺任何一个，运行时都不会按对象真实类型选择方法

## 详解
### 先搞懂：为什么要这三样
还是「喊一声让大家跳舞」的场景。要让不同的人跳出不同的舞，要有三样东西。

- 他们得属于同一个团队（继承）。
- 每人要有自己的舞步（重写）。
- 你得用「团队成员」这个统一身份去喊话（父类引用）。

后文要用的词：
- **继承**：子类用 `extends` 拥有父类能力。
- **重写**：子类写同签名方法，覆盖父类的实现。
- **向上转型**：用父类引用指向子类对象。

### 条件一：继承
子类必须和父类有继承关系，这样子类对象才能被当作父类类型使用。实现接口也可以，接口同样能充当「父类型」。

### 条件二：重写
子类要对父类方法给出自己的实现。如果子类没有重写，调用的就是父类原来的版本。各子类表现一样，也就看不出「多态」。

### 条件三：父类引用指向子类对象
写成 `Animal a = new Dog();`，调用点只知道「是 Animal」。具体执行哪个版本，交给运行时决定。写成 `Dog d = new Dog();`，调用点本来就明确是狗，谈不上多态。

### 三个条件合在一起
代码 `Animal a = new Dog(); a.speak();` 三条都满足，运行时就会调用 `Dog` 重写的 `speak`。

## 示例
```java
class Animal { void speak() { System.out.println("动物叫"); } }
class Dog extends Animal {                      // 条件一：继承
    @Override void speak() { System.out.println("汪汪"); }  // 条件二：重写
}

Animal a = new Dog();                           // 条件三：父类引用指向子类对象
a.speak();                                      // 汪汪
```

## 易错点
- 只记住「继承和重写」，忽略父类引用这一条
- 子类方法名相同但参数不同，那是重载不是重写，不满足条件二
- 方法加了 `static`、`private` 或 `final`，子类无法重写，也没有多态

## 追问
### [f1] 去掉哪个条件，多态就不成立了？
任何一个都不能少。没继承就无法向上转型，没重写各子类行为一样，没用父类引用就没有统一的调用方式。

### [f2] 接口可以实现多态吗？
可以。用接口类型的引用指向实现类对象，调用接口方法，执行的是实现类的版本。
