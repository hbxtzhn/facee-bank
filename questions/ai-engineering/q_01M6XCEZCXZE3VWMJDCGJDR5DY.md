## 一句话
FFN 对每个位置的向量单独做一次非线性加工，补上注意力只做加权混合的不足，也是模型参数的主要来源之一。

## 要点
- [kp1|3] FFN 对序列中每个位置独立计算，位置之间不交换信息
- [kp2|3] 注意力负责在位置间搬运信息，FFN 负责加工每个位置的特征
- [kp3|2] 典型结构是先升维、过激活函数、再降回原维度
- [kp4|2] FFN 的权重在每层里占了大头，是参数量的主要来源之一
- [kp5] 没有 FFN，只堆注意力，模型的表达能力会很受限

## 详解
### 先搞懂：先收集资料，再动手加工
想象你在写一份报告。先开会听大家发言、收集各方信息，这一步就像注意力。散会后你回到自己座位，把收集到的信息消化、整理、提炼成结论，这一步就像 FFN。

开会时人和人之间交流，回座位后每个人各干各的，互不干扰。FFN 也是这样：每个位置拿到注意力混合后的向量，自己单独处理。

后文用到的术语：
- **位置**：序列里的一个 token 对应的那一行向量。
- **非线性**：输出不是输入的简单按比例放缩，比如经过 ReLU 或 GELU 这类激活函数。
- **升维、降维**：先把向量变长，再压回原来的长度。

### FFN 做了什么：升维、激活、降维
FFN 的结构很简单，两层全连接中间夹一个激活函数。

1. 第一层线性变换，把向量从原维度变到更大的维度。
2. 激活函数做非线性处理。
3. 第二层线性变换，再压回原维度。

隐藏层通常比输入维度大好几倍。具体倍数因模型而异，不必死记。

同一层里所有位置共用同一套 FFN 权重，但每个位置各算各的。所以它和序列长度无关，也不会让两个 token 互相影响。

### 为什么需要它：注意力本身不够
注意力的输出，本质上是各个位置的值向量按权重做加权求和。这一步主要是线性的组合，只负责决定从哪里取多少信息。

如果只有注意力，没有非线性，叠再多层也很难学出复杂的特征变换。FFN 的激活函数引入了非线性，让每层都能对信息做更复杂的加工。

可以这样记：注意力解决跟谁交流，FFN 解决交流完怎么想。

### 参数和容量：FFN 是大头
一层里有注意力的几组投影矩阵，也有 FFN 的两层大矩阵。因为 FFN 的隐藏层更宽，它的参数量通常比注意力部分更多。

所以常有人把 FFN 看作模型存放知识的地方。这是研究者提出的一种解释，并非定论，回答时用「有研究认为」这类说法更稳妥。

### 进阶：激活函数与变体（基础薄弱可先跳过）
- 原始 Transformer 用 ReLU，后来很多模型改用 GELU。
- 不少新模型使用带门控的变体，比如 SwiGLU。它多了一组权重，用来控制哪些特征通过。
- 另一类思路是把 FFN 换成多个专家，再按需选用，这就是 MoE（混合专家），参数更多但每次只激活一部分。

## 示例
```python
import torch.nn as nn

class FFN(nn.Module):
    def __init__(self, d_model, d_hidden):
        super().__init__()
        self.up = nn.Linear(d_model, d_hidden)    # 升维
        self.act = nn.GELU()                      # 非线性
        self.down = nn.Linear(d_hidden, d_model)  # 降回原维度

    def forward(self, x):                         # x 形状：批次、序列长度、d_model
        return self.down(self.act(self.up(x)))
```

## 易错点
- 以为 FFN 会让不同位置交换信息；实际它逐位置独立计算，交换信息是注意力的工作
- 以为 FFN 只是个可有可无的小模块；它通常占了每层里最多的参数
- 把「FFN 存放知识」当成定论；这只是目前较流行的一种解释

## 追问
### [f1] FFN 的隐藏层为什么要比输入维度大？
先升维能让模型在更高维的空间里做非线性变换，表达能力更强，最后再降回原维度，方便和残差连接相加。具体倍数是设计选择，没有唯一答案。

### [f2] 去掉激活函数会怎样？
两层线性变换叠在一起，数学上等价于一层线性变换，升维就白做了。所以激活函数是 FFN 能提供非线性能力的关键。

### [f3] MoE 和普通 FFN 是什么关系？
MoE 把一个 FFN 换成多个并列的专家 FFN，再由路由器给每个 token 挑几个专家来算。总参数变多，但每个 token 实际只用一部分。
