## 一句话
Skill 是一份可以被 Agent 发现、按需加载的任务说明，把某类任务的经验、约束和执行顺序沉淀下来。

## 要点
- [kp1|3] Skill 是一份任务说明，记录某类任务该怎么做
- [kp2|3] 它按需加载，用到时才进入上下文，不占用平时的空间
- [kp3|2] 内容包括经验、约束和执行顺序
- [kp4] Skill 沉淀的是方法，不负责连接外部工具

## 详解
### 先搞懂：像老员工写的操作手册
新员工接手一项工作，老员工会给他一份手册：先做什么、后做什么、哪些坑要避开、哪些事绝对不能做。有手册就不用每次从头问。

Skill 就是给 Agent 写的这种手册。下面是后文要用的术语：

- **Agent**：能自己规划并调用工具完成任务的模型应用。
- **按需加载**：需要时才读入内容，而不是一开始全放进去。
- **执行顺序**：做一件事的步骤先后。

### Skill 里有什么
一份 Skill 通常是一个文件夹，核心是一份说明文档，里面写清楚：

- 这个 Skill 适合处理什么任务。
- 做这类任务的步骤和顺序。
- 需要遵守的约束，比如格式要求、禁止事项。
- 积累下来的经验，比如常见错误怎么避免。

### 为什么要按需加载
Agent 可能有很多 Skill。如果全部放进上下文，窗口很快被占满，还会互相干扰。

所以 Agent 平时只看到每个 Skill 的简短描述。判断当前任务需要某个 Skill 时，才把完整说明读进来。

### 用在哪里
比如团队有一套写周报的规范，就可以做成 Skill。Agent 收到写周报的请求时，加载它，就能按规范完成，不用每次在提示词里重复说明。

## 易错点
- 把 Skill 当成工具；Skill 是说明文档，不执行具体动作
- 把所有说明都塞进一个 Skill；应该按任务拆分，才能按需加载
- 以为 Skill 总在上下文里；它只在被判断需要时才加载

## 追问
### [f1] Skill 和普通提示词有什么区别？
提示词是每次对话里直接给出的指令。Skill 是预先沉淀好、可复用的说明，需要时由 Agent 自己发现并加载。
