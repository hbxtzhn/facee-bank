## 一句话
类加载是 JVM 把 .class 字节码文件读进内存，经过验证、准备、解析、初始化，最终生成可以直接使用的 Class 对象的过程。

## 要点
- [kp1|3] 类加载就是把 .class 文件的内容读入内存，变成 JVM 能用的类
- [kp2|3] 过程包括加载、验证、准备、解析、初始化五个阶段
- [kp3|2] 最终在内存中得到一个 `java.lang.Class` 对象，作为访问这个类的入口
- [kp4] 类通常在第一次用到时才加载，不是程序启动时一次性全部加载

## 详解
### 先搞懂：用之前得先把说明书读进来
你写了 `new User()`，但 JVM 一开始并不知道 `User` 长什么样。它得先去找到 `User.class` 文件，把里面描述类的信息读进内存，才能创建对象、调用方法。就像做菜之前，先得把菜谱找出来看懂。

后文用到的术语：
- **字节码文件（.class）**：Java 源码编译后的文件，JVM 能识别。
- **类加载器**：负责找到并读取 .class 文件的组件。
- **Class 对象**：类加载完成后，JVM 在内存里生成的、代表这个类的对象。

### 类加载做了什么
大致分五步：
1. **加载**：根据类名找到字节码，读入内存，生成 Class 对象；
2. **验证**：检查字节码是否合法、安全；
3. **准备**：给静态变量分配内存，赋默认值；
4. **解析**：把字节码里的符号引用换成真正的内存地址；
5. **初始化**：执行静态变量赋值和静态代码块。

经过这些步骤，这个类才算真正可用。

### 什么时候触发
类一般是第一次被用到时才加载，比如创建对象、调用静态方法、访问静态变量。没有用到的类，不会被加载。这样可以节省启动时间和内存。

### 谁来加载：类加载器
读取字节码的工作由类加载器完成。JDK 自带几种类加载器，它们按"双亲委派"的规则分工合作，这些在后面的题目里单独讲。

## 示例
```java
public class Main {
    public static void main(String[] args) throws Exception {
        // 第一次用到时才加载
        Class<?> c = Class.forName("java.util.ArrayList");
        System.out.println(c.getName());
    }
}
```

## 易错点
- 以为程序启动时所有类都会被加载；实际是用到时才加载
- 以为类加载只是读文件；后面还有验证、准备、解析、初始化
- 把类加载和创建对象混为一谈；类加载一次，之后可以创建很多对象

## 追问
### [f1] 类加载过程中的初始化什么时候发生？
通常在第一次主动使用类时，比如创建对象、调用静态方法或访问静态变量。初始化会执行静态变量赋值和静态代码块。
