模拟依赖允许测试主动指定“模型返回什么”“发送端返回哪个结果”，从而稳定重现故障。项目群 Agent 的测试中可见脚本化模型回复、内存数据库和模拟路由发送端，用来观察认领、记忆和投递结果，而无需真的调用模型或向群里发消息。

例如让模拟发送端返回成功、拒绝或不确定，检查不同状态如何影响本轮记录；也可以给同一条轮次 ID 再次提交，检查是否再次调用处理逻辑。由于输入和结果可控，这些测试适合保护已知边界并防止后续代码改坏。

它的局限同样明确：模拟对象只反映测试作者设计的行为，不能证明第三方平台在所有网络故障下都会按模拟方式返回，也不能验证实际模型质量或真实部署权限。代码阅读和测试执行结果应分别报告。
