## 一句话
OSI 七层从上到下是应用层、表示层、会话层、传输层、网络层、数据链路层、物理层，每层各管一件事。

## 要点
- [kp1|3] 七层从上到下：应用、表示、会话、传输、网络、数据链路、物理
- [kp2|3] 应用层面向用户程序，传输层管端到端，网络层管选路
- [kp3|2] 数据链路层管相邻节点之间的帧传输，物理层管比特的电信号传输
- [kp4] 表示层管数据格式转换和加解密，会话层管通信的建立和维持

## 详解
### 先搞懂：寄快递的流程
寄一件包裹，从你写寄件信息到快递员把它送到对方手里，要经过好几个环节：填单、打包、选路线、一段段运输、真正的车辆运输。OSI 模型就是把网络通信也拆成七个环节，每个环节只做一件事。

后文的术语：

- **OSI**：一个理论上的网络分层参考模型，用来帮助理解网络通信。
- **帧**：数据链路层传输的数据单位。
- **比特**：0 和 1，物理层传输的最小单位。

### 七层各管什么：从上往下
- **应用层**：最靠近用户，提供网络服务和应用程序之间的接口，比如浏览器用的 HTTP、发邮件用的 SMTP。
- **表示层**：处理数据的格式，负责转换、压缩、加解密，让一台机器发出的数据能被另一台机器读懂。
- **会话层**：管理两台机器之间的会话，负责建立、维持和结束通信。
- **传输层**：负责端到端的数据传输，两台主机上程序之间的通信，代表协议是 TCP 和 UDP。
- **网络层**：负责选路和转发，用 IP 地址标识主机，让数据包能跨越多个网络，代表协议是 IP。
- **数据链路层**：负责相邻两个节点之间的数据传输，使用 MAC 地址，数据单位是帧，还负责发现传输错误。
- **物理层**：负责在网线、光纤、无线电波上真正传输比特，规定接口、电压等物理特性。

### 记忆方法
可以按「谁和谁通信」来记：应用到会话三层是面向程序的，传输层是主机上的程序之间，网络层是主机到主机，下面两层是相邻设备之间。

### OSI 和实际网络的关系
OSI 是理论模型。实际互联网使用的是 TCP/IP 协议，它把应用、表示、会话三层合成一个应用层。所以面试中既要会背七层，也要知道真正跑的是 TCP/IP。

## 易错点
- 以为 HTTP 属于传输层；HTTP 是应用层协议，传输层的是 TCP 和 UDP
- 以为 IP 地址和 MAC 地址在同一层；IP 属于网络层，MAC 属于数据链路层
- 以为实际网络严格按七层实现；真实的互联网用的是 TCP/IP 的四层结构

## 追问
### [f1] 路由器和交换机分别工作在哪一层？
路由器主要工作在网络层，根据 IP 地址转发。传统的交换机主要工作在数据链路层，根据 MAC 地址转发。
