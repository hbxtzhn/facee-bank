### 一句话总结

SQL 参数绑定隔离 SQL 语法，但 FTS MATCH 参数仍会被全文查询语法解释。

### 回答要点

1. 使用参数化 SQL 避免 SQL 注入，同时按产品需要构造受控的 FTS 词或短语；不要直接把原始问题当作任意高级查询表达式。

2. 引号与运算符需要按 FTS 语法安全处理，输入还要限制长度和候选数量。普通用户词面搜索与高级搜索应采用不同入口或显式模式。

3. 测试引号、逻辑运算符、空白、超长文本和非文本输入，确认错误不会退化成无界全表扫描。

### 常见误区与边界

防止 SQL 注入不等于已经限制了搜索表达式的全部行为。
