### 一句话总结

按 ID 查到资源之后，还必须验证该资源属于当前主体与允许范围。

### 回答要点

1. 优先在查询条件中同时携带账号或租户范围，避免先取全部对象再靠调用方过滤；单条详情、导出和附件下载都要一致。

2. 使用随机不透明 ID 可以降低枚举便利，但不是授权。错误响应也应避免暴露不必要的资源存在性。

3. 用 A、B 两个合成账号构造相同路径的正反测试，覆盖读取、更新、删除和关联资源，而不是只测登录检查。

### 常见误区与边界

不要把 ID 难猜当作访问控制。
