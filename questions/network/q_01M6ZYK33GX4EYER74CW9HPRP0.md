## 一句话
DNS 是互联网的「电话簿」，把好记的域名翻译成 IP 地址，让浏览器能找到目标服务器。

## 要点
- [kp1|3] DNS 的作用是把域名解析成 IP 地址
- [kp2|3] 网络通信最终靠 IP 地址，域名只是方便人记忆
- [kp3|2] 解析结果会被缓存，下次访问可以更快
- [kp4] 同一个域名可以对应多个 IP，也可以随时更换 IP 而不影响用户

## 详解
### 先搞懂：手机通讯录
你想给朋友打电话，只需要在通讯录里点他的名字，不需要记住他的号码。手机通讯录帮你把名字翻成号码。

DNS 就是这个通讯录：

- 人记名字，所以有域名，比如 `www.example.com`。
- 网络设备靠号码找人，所以有 IP 地址，比如 `93.184.216.34`。
- DNS 负责把域名翻译成 IP 地址。

后文的术语：

- **域名**：便于人记忆的网站名字。
- **IP 地址**：服务器在网络里的地址。
- **DNS 服务器**：存放和提供「域名对应哪个 IP」信息的服务器。
- **解析**：把域名翻译成 IP 的过程。

### 为什么需要 DNS
- 域名好记，IP 地址难记，尤其是更长的 IPv6 地址。
- 服务器的 IP 可能变化，比如换机房、迁移服务。有了 DNS，只要把域名指向新的 IP。用户仍然访问同一个域名，感觉不到变化。
- 一个域名可以对应多个 IP，实现简单的负载分担，把用户分到不同服务器上。

### DNS 怎么用：一次访问中的位置
浏览器访问网站时，第一步就是 DNS 解析。浏览器先查自己缓存里有没有。没有就向本地 DNS 服务器询问。必要时，它再向更上层的服务器逐级查询。最后拿到 IP 地址，浏览器再去连接这个 IP。

### 缓存让 DNS 更快
解析过的结果会被浏览器、操作系统和本地 DNS 服务器缓存一段时间。在缓存有效期内，再访问同一个域名就不用重新查询。这也是修改了域名指向后，要等一段时间才对所有用户生效的原因。

## 易错点
- 以为访问网站必须经过 DNS；直接输入 IP 访问就不需要
- 以为改了 DNS 记录会立刻对所有人生效；缓存过期之前，有的用户仍会得到旧地址
- 以为一个域名只能对应一个 IP；一个域名可以配置多个 IP

## 追问
### [f1] DNS 通常用什么协议？
DNS 查询通常使用 UDP，因为请求和响应都很短，UDP 开销小。当响应内容太大等情况时，也会使用 TCP。
