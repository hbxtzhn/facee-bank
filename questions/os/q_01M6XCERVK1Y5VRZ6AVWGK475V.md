## 一句话
信号量是一个表示可用资源数量的计数器：P 操作申请资源，计数减一，不够就阻塞；V 操作释放资源，计数加一。

## 要点
- [kp1|3] 信号量本质是一个整数，表示当前可用资源的数量
- [kp2|3] P 操作：值大于 0 就减一并继续；否则线程阻塞等待
- [kp3|2] V 操作：值加一，并唤醒一个等待的线程
- [kp4] 初始值为 1 时，可以当作互斥锁使用

## 详解
### 先搞懂：停车场的空位牌
停车场门口有块牌子，写着剩余车位数。车进去，数字减一；数字是 0，后来的车就在门口等；有车出来，数字加一，放一辆等待的车进去。

这个牌子就是信号量。后文会用到几个词：

- **信号量**：记录剩余资源数的计数器。
- **P 操作**：申请资源（等待）。
- **V 操作**：释放资源（通知）。
- **原子**：操作整体不可被打断。

### P 操作：申请资源
线程想用资源时执行 P。如果计数大于 0，就把它减一，线程继续往下走。如果计数是 0，线程被阻塞，直到有人释放。

### V 操作：释放资源
线程用完资源执行 V：计数加一。如果有线程正在等，就唤醒其中一个。

### 两个用途
- **限制并发数**：初始值设为 N，最多 N 个线程能同时使用资源，比如限制同时访问数据库的连接数。
- **互斥**：初始值设为 1，只有一个线程能拿到，效果和互斥锁一样。

### 和互斥锁的区别
互斥锁只有锁住和没锁住两种状态；信号量可以表示多个资源。信号量还能用来在线程之间传递「事件发生了」的信号，不要求申请和释放是同一个线程。

## 示例
```java
import java.util.concurrent.Semaphore;

Semaphore sem = new Semaphore(3);   // 最多 3 个线程同时进入

sem.acquire();                      // P 操作
try {
    // 使用资源
} finally {
    sem.release();                  // V 操作
}
```

## 易错点
- 以为信号量只能做互斥；它更常用来限制并发数
- 申请后忘记释放，计数一直变小，最终所有线程都被阻塞
- 以为信号量的初始值不重要；值设错，限流或互斥就会失效

## 追问
### [f1] 信号量初始值为 0 有什么用？
可以让一个线程先等，另一个线程完成后执行 V，把它叫醒，用来表示先后顺序。
