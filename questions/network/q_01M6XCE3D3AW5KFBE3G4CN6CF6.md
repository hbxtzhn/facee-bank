## 一句话
IP 地址标识网络中的哪台主机，端口标识这台主机上的哪个程序；两者合起来，才能准确找到一个具体的服务。

## 要点
- [kp1|3] IP 地址用来找到是哪台主机，端口用来找到是主机上的哪个程序
- [kp2|3] 端口号是 16 位整数，范围 0 到 65535
- [kp3|2] 常见端口：HTTP 为 80，HTTPS 为 443，MySQL 默认 3306
- [kp4] 端口属于传输层，TCP 和 UDP 各有一套端口

## 详解
### 先搞懂：楼栋号加房间号
一栋公寓楼里住着很多人。快递员要送到你手里，既要知道是哪栋楼（地址），还要知道是几号房间（房间号）。只有楼栋号，包裹到了楼下没人收。

网络里也是这样：

- **IP 地址**：像楼栋号，指明数据要送到哪台主机。
- **端口**：像房间号，指明数据要交给这台主机上的哪个程序。

一台服务器同时运行着网站、数据库、远程登录等服务，它们共用同一个 IP，靠不同的端口区分。

### IP 地址：找到主机
IP 地址在网络层使用，路由器根据它决定数据往哪转发。数据包经过多个网络，最终到达目标主机。

### 端口：找到程序
数据到达主机后，操作系统要决定交给哪个程序。这时看传输层首部里的目的端口。程序启动时，会告诉操作系统「我监听某个端口」，之后发到这个端口的数据就交给它。

端口号是 16 位的整数，范围是 0 到 65535。常见的端口有：

- 80：HTTP。
- 443：HTTPS。
- 22：SSH 远程登录。
- 3306：MySQL 默认端口。

### 两者合起来：定位一个连接
一条 TCP 连接，通常由源 IP、源端口、目的 IP、目的端口这四项来唯一标识。浏览器访问网站时，目的 IP 和端口指明了要找的服务，源端口则由操作系统临时分配一个，用来区分同一台机器上的多个连接。

## 易错点
- 以为一个端口只能被一台电脑使用；端口是每台主机各自一套的，只在本机内唯一
- 以为 TCP 和 UDP 共用端口；它们各有一套端口，互不冲突
- 以为只要有 IP 就能访问服务；没有指定正确端口，数据交不到对应的程序

## 追问
### [f1] 同一台服务器能同时让多个客户端连同一个端口吗？
可以。服务器的端口只有一个，但每条连接由源 IP、源端口、目的 IP、目的端口四项区分，不同客户端的连接互不冲突。
