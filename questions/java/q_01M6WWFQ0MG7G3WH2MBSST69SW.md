## 一句话
构造方法是与类同名、没有返回值的特殊方法，在用 new 创建对象时自动调用，用来初始化对象的属性。

## 要点
- [kp1|3] 构造方法名必须和类名相同，且不写返回类型（连 void 也没有）
- [kp2|3] new 创建对象时自动调用，用来给属性设置初始值
- [kp3|2] 类里没写任何构造方法时，编译器会自动提供一个无参构造
- [kp4] 构造方法可以重载，也不能被子类继承

## 详解
### 先搞懂：新生儿登记
一个孩子出生时要登记姓名、生日。对象也一样：刚创建出来时，就应该带上必要的信息，比如订单要有订单号、金额。构造方法就是创建对象时的「登记表」。

后文要用的词：
- **初始化**：给对象的属性设置第一次的值。
- **无参构造**：没有参数的构造方法。

### 怎么写
```java
class User {
    String name;
    User(String name) { this.name = name; }  // 构造方法
}
User u = new User("张三");
```
名字和类名一样，前面没有返回类型。`new User("张三")` 时，JVM 先创建对象，然后调用这个构造方法。

### 默认构造方法
如果一个类里没写任何构造方法，编译器会补一个无参的。但是一旦你自己写了任何构造方法，编译器就不再补了。这时候如果还想用 `new User()`，要自己再写一个无参构造。

### 构造方法的几个特点
- 可以**重载**：写多个参数不同的构造方法，适应不同的创建方式。
- 不能被**继承**，但子类构造时会先调用父类的构造方法。
- 不能用 `static`、`final` 等修饰。

### 构造方法之间的调用
同一个类中，可以用 `this(...)` 调用另一个构造方法；子类用 `super(...)` 调用父类构造方法，都必须放在第一行。

## 易错点
- 在构造方法前加了返回类型，它就变成了普通方法，不再是构造方法
- 自己写了带参构造后，直接 `new User()` 编译报错，因为默认无参构造不再提供
- 以为构造方法能创建对象；对象是 new 先创建好的，构造方法只负责初始化

## 追问
### [f1] 构造方法能被重写吗？
不能。构造方法不会被继承，所以没有重写，只能重载。

### [f2] 父类没有无参构造，子类怎么办？
子类构造方法里必须用 `super(参数)` 显式调用父类存在的某个构造方法，否则编译报错。
