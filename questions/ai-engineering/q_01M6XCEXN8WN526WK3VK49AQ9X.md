## 一句话
大模型每次根据已有的上文预测下一个 token，把它接到末尾，再接着预测，如此循环，直到遇到结束符或达到长度上限，这就是自回归生成。

## 要点
- [kp1|3] 每一步只预测一个 token，输出依赖前面所有已有内容
- [kp2|3] 新 token 追加到上下文末尾，作为下一步的输入，循环往复
- [kp3|2] 遇到结束符或达到最大长度就停止
- [kp4] 每步得到的是候选词的概率分布，再按采样策略选一个

## 详解
### 先搞懂：像手机输入法的联想，一个字一个字续写
你用输入法打字，它会猜你下一个词。选了一个词，它再根据现在的整句话猜再下一个词。

大模型生成回答，本质上就是这样续写，只是它猜得准得多。你看到的一大段话，是一次次“猜下一个”拼出来的。

后文用到的词：
- **token**：模型处理文本的基本单位，可能是一个字、一个词或词的一部分。
- **上下文**：模型当前能看到的全部已有内容，包括你的问题和它已经写的部分。
- **概率分布**：模型给每个候选 token 打的概率，加起来是 1。
- **自回归**：用自己前面的输出，作为后面的输入。

### 生成循环：一步一步怎么走
1. 把你的问题切成 token，作为初始上下文。
2. 模型读完整个上下文，给词表里每个 token 算一个概率。
3. 按采样策略（比如取概率最高的，或按概率随机抽）选出一个 token。
4. 把这个 token 接到上下文末尾。
5. 回到第 2 步，用更长的上下文预测下一个。
6. 遇到结束符，或达到设定的最大输出长度，停止。

### 为什么这样设计
- 每步都能看到前面写了什么，所以前后文能连贯。
- 一次只定一个 token，实现简单，也方便在每一步用采样参数控制风格。

### 它带来的特点
- **一个个吐字**：所以接口常用流式输出，边生成边显示。
- **前面写错，后面会受影响**：因为后面的内容都建立在前面已生成的内容上。
- **输出越长，生成越久**：每多一个 token 就多一轮计算。

## 示例
```python
# 伪代码：自回归生成循环
tokens = tokenize(prompt)
while len(tokens) < max_len:
    probs = model(tokens)        # 预测下一个 token 的概率分布
    nxt = sample(probs)          # 按策略选一个
    tokens.append(nxt)
    if nxt == EOS:               # 结束符
        break
```

## 易错点
- 以为模型先想好整段答案再输出；实际是逐 token 往后推
- 以为生成的是一整句话；每一步只产出一个 token

## 追问
### [f1] 为什么调大 Temperature 会让输出不一样？
因为每一步是按概率分布选 token，Temperature 改变分布的平滑程度，选择就更随机或更确定。

### [f2] 什么时候会停止生成？
模型生成了结束符，或者达到调用方设定的最大输出长度。
