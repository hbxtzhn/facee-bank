## 一句话
状态码按第一位数字分五类：1xx 提示、2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务端错误。

## 要点
- [kp1|3] 五类：1xx 提示，2xx 成功，3xx 重定向，4xx 客户端错，5xx 服务端错
- [kp2|3] 200 成功并带数据，204 成功但没有响应体
- [kp3|2] 301 永久重定向，302 临时重定向，304 表示用本地缓存
- [kp4|2] 4xx 是请求有问题，5xx 是服务器自己出了问题
- [kp5] 206 用于只返回资源的一部分，如断点续传

## 详解
### 先搞懂：状态码是服务器的回话
你在浏览器打开一个网页，服务器除了返回内容，还会先给一个三位数字，告诉你这次请求的结果。这就像点外卖时，商家先回你一句「接单了」「没货了」「我们出问题了」。

后文要用的术语：

- **状态码**：响应里的三位数字，说明请求的处理结果。
- **重定向**：服务器告诉浏览器「去另一个地址再请求一次」。

### 五大类：看第一位就知道大方向
- **1xx 提示信息**：请求已收到，还在处理中，属于中间状态，平时很少见到。
- **2xx 成功**：请求已被正确处理。
- **3xx 重定向**：要完成请求，还得做进一步操作，比如换个地址。
- **4xx 客户端错误**：请求本身有问题，服务器没法处理。
- **5xx 服务端错误**：请求没问题，服务器处理时出了故障。

记住这一条，排查问题就有方向：4xx 先查请求，5xx 先查服务端。

### 常见状态码：记住这几个就够用
| 状态码 | 含义 | 什么时候见到 |
|---|---|---|
| 200 | 成功，带响应体 | 正常访问页面、调用接口 |
| 204 | 成功，没有响应体 | 删除成功，不需要返回内容 |
| 206 | 部分内容 | 断点续传、视频分段加载 |
| 301 | 永久重定向 | 网站换了新地址 |
| 302 | 临时重定向 | 未登录时临时跳到登录页 |
| 304 | 没有修改 | 浏览器缓存还能用 |
| 400 | 请求有误 | 参数格式错误 |
| 401 | 未认证 | 没登录 |
| 403 | 禁止访问 | 登录了但没权限 |
| 404 | 找不到资源 | 地址写错了 |
| 500 | 服务器内部错误 | 服务端代码抛异常 |
| 502 | 网关错误 | 网关从后端拿到无效响应 |
| 503 | 服务不可用 | 服务器过载或维护中 |

其中 304 比较特别：它不是让你换地址，而是告诉浏览器「内容没变，直接用你本地缓存的那份」。

## 易错点
- 把 304 当成错误；它是正常的缓存命中，不是失败
- 分不清 401 和 403；401 是没有认证，403 是认证了但没权限
- 以为 204 的响应里也有数据；204 没有响应体

## 追问
### [f1] 301 和 302 有什么区别？
301 表示永久搬家，浏览器和搜索引擎会记住新地址；302 表示临时跳转，原地址之后还会继续使用。

### [f2] 502 和 504 有什么区别？
502 是网关收到了后端的无效响应；504 是网关等后端响应超时了。
