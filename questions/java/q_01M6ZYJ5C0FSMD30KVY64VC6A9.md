## 一句话
类是对象的模板，描述这类事物有哪些属性和行为；对象是按这个模板创建出来的一个具体实例，用 new 创建。

## 要点
- [kp1|3] 类是模板，定义属性（字段）和行为（方法）
- [kp2|3] 对象是类的实例，用 new 创建，一个类可以创建多个对象
- [kp3|2] 每个对象有自己的一份属性值，互不影响
- [kp4] 对象存放在堆内存，变量里保存的是它的引用

## 详解
### 先搞懂：图纸和房子
一张房屋图纸规定了有几间房、多大面积。按图纸可以盖很多栋房子，每栋房子是真实存在的，各有自己的家具、住户。

类就是图纸，对象就是房子。做项目时，`User` 是类，描述“用户有姓名、年龄，能登录”；张三、李四是两个具体的 User 对象。

后文术语：
- **属性（字段）**：对象身上记录的数据，如姓名。
- **方法**：对象能做的事，如登录。
- **实例**：对象的另一个叫法，“某类的实例”。

### 类里有什么
```java
class User {
    String name;        // 属性
    int age;
    void login() { }    // 行为
}
```
这只是模板，本身不占一个具体用户的数据。

### 怎么创建对象
`new User()` 会在堆内存里创建一个对象，并返回它的引用。`User u = new User();` 里的 u 保存的是这个对象的引用。可以再 new 一个，得到另一个独立对象。

### 对象之间互不干扰
```java
User a = new User();
User b = new User();
a.name = "张三";
// b.name 仍然是默认值 null
```
每个对象有自己的属性值。方法的代码则是整个类共用的一份。

## 示例
```java
User a = new User();
a.name = "张三";
User b = new User();
b.name = "李四";
```

## 易错点
- 以为类本身就是一个具体的数据；类只是模板，要创建对象才有数据
- 以为 `User b = a` 创建了新对象；这只是让 b 引用同一个对象
- 以为对象变量里存着整个对象；存的是引用

## 追问
### [f1] 类和对象有什么区别？
类是抽象的模板，对象是具体的实例。类在代码里定义一次，对象可以按需创建很多个。
