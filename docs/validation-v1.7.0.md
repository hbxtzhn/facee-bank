# FaceE 题库 v1.7.0 核验记录

本版以 100 道 AgentHub 深度学习题替换此前的 120 道项目题，所有新题归入同一个「AgentHub · 项目面试」分类；其他 650 道题的题目文件与目录元数据保持原样。每道新题包含详细答案和至少两道有答案的追问，共 204 道追问。另有项目快速理解与题目索引。

题目以经授权的项目材料为依据，并为解释机制构造例子。源码阅读不能证明线上配置、生产效果和个人分工；假设性的优化不代表已上线。私有代码、日志和本机路径不包含在公开题库中。

## 校验范围

- 使用 FaceE 题库规范的目录校验器和 ZIP 校验器检查，均为 0 错误；保留旧版已有的 78 个非阻断警告。
- 检查 100 个新题 ID、标题唯一、每题答案与追问齐全、旧版 AgentHub 题目不在新版中，且其他 650 道题的题目文件与元数据保持一致。
- 对公开题目进行源码路径、私人路径和部分私有项目标识的模式检查；这种检查不能替代逐条审核。
- 未执行 Android 或 iOS 实机导入，也未查询线上项目配置、调用真实模型或发送真实消息。

新版使用新的题目 ID。FaceE 的掌握度按题库和题目 ID 关联，旧题的掌握记录不会自动对应到重写后的新题。
