## 1. `is` vs `==` 的本质区别

- **`==`（值相等性）**：比较两个对象包含的**数据内容（Value）**是否相等，底层调用对象的 `__eq__()` 方法。
- **`is`（同一性）**：比较两个变量所引用的**内存地址（Identity）**是否完全相同，底层直接比对两者的指针地址（即 `id(a) == id(b)`）。

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True （内容完全一致）
print(a is b)  # False（两个独立的列表对象，内存地址不同）
```

## 2. 小整数对象池（Small Integer Cache）

在日常编程中，小数字（如 0, 1, -1, 100 等）被使用的频率极其高。如果每次用到这些数字都向系统申请一块新的 `PyObject` 内存，会造成极大的内存碎片和性能浪费。

- CPython 在解释器初始化启动时，直接在全局静态分配好了 **`[-5, 256]`** 闭区间内所有整数的对象实体；
- 在整个运行期间，任何创建这个范围内整数的操作，都不会申请新内存，而是直接返回指向全局对象池中的固定引用。

```python
x = 100
y = 100
print(x is y)  # True

x = 1000
y = 1000
print(x is y)  # 可能为 False（超出 [-5, 256] 范围）
```

## 3. 字符串驻留机制（String Interning）

对于符合 Python 标识符命名规范（即仅由字母、数字、下划线组成）的不可变字符串，CPython 会在内部维护一个全局的字典缓存进行**驻留（Interning）**：
- 相同的不可变字符串在内存中全局只保存一份；
- **好处**：不仅节省重复文本的内存占用，更重要的是使字典（dict）的查找操作速度暴增——因为在比对 key 时，只要两者的指针相同（`a is b`），就无需再耗费 CPU 逐个字符比对内容。
