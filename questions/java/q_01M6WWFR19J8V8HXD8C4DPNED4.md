## 一句话
方法重载就是在同一个类里写多个方法名相同、参数列表不同（个数或类型不同）的方法，调用时按传入的参数选择对应的版本。

## 要点
- [kp1|3] 重载要求方法名相同，参数列表不同（个数、类型或顺序）
- [kp2|3] 只有返回值不同不算重载，编译会报错
- [kp3|2] 重载发生在同一个类中（子类也可以重载继承来的方法）
- [kp4] 调用哪个重载版本在编译期就根据参数类型确定

## 详解
### 先搞懂：同一个动作，不同的材料
你在日志里常见 `log("hello")`、`log("hello", 3)`，都是「记日志」，只是给的材料不同。如果每种都要起不同名字，代码会很难读。重载就是让同一个名字对应多个参数不同的版本。

后文要用的词：
- **方法签名**：方法名加参数列表。
- **参数列表**：参数的个数、类型和顺序。

### 怎么判断是重载
满足：方法名相同；参数列表不同。以下都算「不同」：
- 个数不同：`add(int a)` 与 `add(int a, int b)`；
- 类型不同：`add(int a)` 与 `add(double a)`；
- 顺序不同：`f(int a, String b)` 与 `f(String b, int a)`。

### 什么不算
- 只有返回类型不同：`int f()` 和 `void f()` 不能共存，编译报错，因为调用时编译器无法区分。
- 只有参数名不同、只有访问修饰符不同，也不算重载。

### 调用时怎么选
编译器根据你传入的实参类型，在编译期就选好具体调用哪个。如果没有完全匹配的，会尝试自动类型转换，比如 `int` 提升为 `long`，再选最合适的。

### 为什么要用重载
让同一类功能共用一个名字，提高可读性，调用方不用记一堆名字。

## 示例
```java
class Printer {
    void print(int n)        { System.out.println("int " + n); }
    void print(String s)     { System.out.println("String " + s); }
    void print(int a, int b) { System.out.println(a + b); }
}
```

## 易错点
- 以为返回值不同就能重载；不能，返回值不参与区分
- 把重载和重写混淆；重载是同类里同名不同参，重写是子类改父类的方法
- 传入 null 时，若有多个引用类型的重载可选，可能出现编译歧义

## 追问
### [f1] 构造方法能重载吗？
能，一个类可以有多个参数不同的构造方法。

### [f2] 重载是多态吗？
一般说的多态指重写带来的运行时多态。重载在编译期就确定了调用哪个方法，有时被称为编译期多态，但面试中通常特指重写。
