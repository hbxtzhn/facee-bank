## 一句话
路由器连接不同的网络，根据数据包的目的 IP 查路由表，把它转发给下一跳，一站一站送往目的网络。

## 要点
- [kp1|3] 路由器工作在 IP 层，连接多个不同的网络
- [kp2|3] 它根据数据包的目的 IP 地址查路由表，选择转发方向
- [kp3|2] 路由器只决定下一跳，不负责整条路径
- [kp4] 路由表可以手工配置，也可以由路由协议自动生成

## 详解
### 先搞懂：路口的指示牌
你开车去外省，沿途每个路口都有指示牌：去哪个城市，往哪个方向走。你不需要知道全程怎么走，只要每个路口按牌子走，最终就能到。

路由器就是网络里的路口。数据包到达它，它看一眼目的 IP，查表决定往哪个方向发出去。几个词：

- **路由表**：路由器里的一张表，记录“去某个网络，该交给哪个下一站”。
- **下一跳**：数据包下一个要交给的设备。
- **网络**：IP 地址里表示网络位置的那部分对应的一组主机。

### 路由器是怎么转发的
按发生顺序：

1. 路由器收到一个数据包，读出目的 IP 地址；
2. 在路由表里找最合适的一条记录，也就是目的地址所属的网络；
3. 找到了，就把数据包交给表里写的下一跳；
4. 下一跳设备重复同样的动作，直到数据包到达目标网络，由最后一个路由器交给目的主机。

如果表里没有合适的记录，通常会走默认路由，没有默认路由就丢弃数据包。

### 路由表从哪来
- **手工配置**：管理员写好每条规则，适合小而稳定的网络；
- **动态学习**：路由器之间用路由协议互相交换信息，自动更新路由表，网络变化时能自己调整。

### 为什么这样设计
每个路由器只关心“下一跳往哪”，不需要知道全程。这样路由器的工作量可控，网络规模再大也能运转。

## 易错点
- 以为路由器知道数据包的完整路径；它只决定下一跳
- 以为路由器根据 MAC 地址转发；它在 IP 层，根据 IP 地址转发
- 以为家里的路由器只做 WiFi；它的核心功能是连接不同的网络并转发

## 追问
### [f1] 路由器和交换机有什么区别？
交换机通常在同一个局域网内，根据 MAC 地址转发；路由器连接不同的网络，根据 IP 地址转发。
