## 追问 1：在类中定义 __del__ 方法对循环引用的回收有什么危害？

在 Python 3.4 之前（PEP 442 实现前），如果循环引用链中的对象定义了 __del__，GC 无法确定安全的析构调用顺序，会将对象放入 gc.garbage 导致永久内存泄漏。Python 3.4+ 修复了这一行为，但仍不推荐滥用 __del__，应优先使用上下文管理器 with 显式释放资源。

## 追问 2：什么时候需要用到 weakref（弱引用）？

弱引用不阻止目标被回收，适合 WeakValueDictionary 缓存或 WeakMethod 观察者回调等场景。它不保证对象仍然存在，读取时必须处理已回收状态；functools.lru_cache 默认持有强引用，不能把一般 LRU 缓存直接当成弱引用机制的例子。
