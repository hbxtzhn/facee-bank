来源链接用于让用户查看依据，但如果直接把不可信字符串拼进答案，可能生成错误地址、跳转到非预期位置，或使 Markdown 显示被特殊字符破坏。项目对部分来源 ID 和站内路径施加格式限制，并对展示标题中的换行与 Markdown 特殊字符进行处理。

网页边缘查询中，条目链接只有符合 ID 格式的值才会构造；公开问答链接也经过受控的站内路径检查。后续生成来源 Markdown 时处理标题中的特殊字符并限制显示长度。每层解决不同问题：链接格式检查不是权限检查，标题转义也不等于确认来源内容正确。

例如数据库里某条问答的链接字段格式异常，系统应避免直接把它作为可点击来源；另一方面，即使链接格式正确，也仍需确认对应资料对当前用户可见并且实际支持回答。
