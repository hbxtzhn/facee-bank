## 一句话
Agent 先推理决定下一步，再调用工具行动，把工具结果当作观察放回上下文，如此循环，直到任务完成或触发停止条件。

## 要点
- [kp1|3] 一轮循环包括推理、行动、观察三步
- [kp2|3] 观察会追加到上下文，成为下一轮推理的依据
- [kp3|2] 循环在任务完成或触发停止条件时结束
- [kp4|2] 常见停止条件有最大轮次、超时和模型给出最终答案

## 详解
### 先搞懂：像修水管
水管漏水，你先判断可能是接口松了，这是推理。拿扳手拧一拧，这是行动。再看还漏不漏，这是观察。还漏的话，你会换个判断，比如换密封圈，如此反复，直到不漏为止。

Agent 就是这样循环干活的。

后文用到的术语：
- **推理**：模型分析当前情况，决定下一步。
- **行动**：调用某个工具。
- **观察**：工具返回的结果。
- **停止条件**：让循环结束的规则。

### 一轮循环发生了什么
1. **推理**：模型根据任务和已有信息，判断下一步该做什么；
2. **行动**：模型输出要调用的工具和参数，由外部程序执行；
3. **观察**：程序把执行结果放回上下文；
4. 回到第 1 步，模型带着新信息继续推理。

每一轮都比上一轮多了新的信息，所以它能逐步逼近目标。

### 什么时候停下来
- 模型判断任务已完成，直接给出最终答案；
- 达到最大轮次，防止无限循环；
- 超时、费用超限，或出现需要人确认的情况。

没有停止条件的 Agent 可能一直调用工具，白白消耗成本。

### 对比：有循环和没有循环
| 对比点 | 一次性回答 | 推理-行动-观察循环 |
|---|---|---|
| 步骤数 | 一步 | 多步 |
| 能否根据结果调整 | 不能 | 能 |
| 风险 | 凭记忆乱答 | 可能死循环，需限制轮次 |

结论：任务需要查资料、试错、多步操作时用循环；单步问答无需循环。

## 示例
```python
for step in range(MAX_STEPS):                 # 最大轮次是停止条件之一
    reply = llm(messages, tools)              # 推理
    if reply.is_final:
        break
    result = run_tool(reply.tool_call)        # 行动
    messages.append(result)                   # 观察
```

## 易错点
- 以为循环会自己停；必须设置最大轮次等停止条件
- 以为每一轮都会调用工具；模型也可能直接给出最终答案结束
- 以为观察只是日志；它是下一轮推理的输入

## 追问
### [f1] Agent 陷入重复调用同一工具怎么办？
设置最大轮次，并检测重复调用。也可以在上下文里提醒模型换思路，或转交给人处理。

### [f2] 这个循环和 ReAct 是什么关系？
ReAct 就是这种循环的一种具体模式：每一步先推理再行动，拿到观察后再推理。
