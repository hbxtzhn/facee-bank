## 一句话
交换空间（swap）是磁盘上专门存放被换出内存页的区域，物理内存不够用时，系统把不常用的页搬到这里腾出内存。

## 要点
- [kp1|3] swap 是磁盘上的一块区域，用来存放被换出的内存页
- [kp2|3] 物理内存不足时，把不常用的页换出到 swap，腾出内存
- [kp3|2] 页再次被访问时，通过缺页中断从 swap 换回内存
- [kp4] 磁盘比内存慢得多，频繁换入换出会让系统明显变慢

## 详解
### 先搞懂：书桌和抽屉
书桌（物理内存）空间有限，桌上摆满了书。这时你想再看一本新书，就把桌上暂时不看的书收进抽屉（swap），腾出位置。以后想看抽屉里的书，再拿出来，但这需要多花点时间。

后文用到的术语：

- **页**：操作系统管理内存的固定大小的块。
- **换出 / 换入**：把页从内存写到 swap 叫换出，从 swap 读回内存叫换入。
- **缺页中断**：访问的页不在内存时触发的中断。

### 交换空间是什么
Linux 把物理内存分成一页一页的。内存紧张时，系统挑一些不常用的页，把内容写到磁盘上的一块区域，然后把这些页框释放出来给别人用。这块区域就是交换空间，可以是单独的分区，也可以是文件。

### 怎么用起来
1. 内存不足，系统通过置换算法挑出一些不常用的页；
2. 这些页的内容写入 swap，对应页表项标记为“不在内存”；
3. 之后程序访问这一页，触发缺页中断；
4. 系统把页从 swap 读回内存，更新页表，程序继续运行。

### 作用和代价
- **作用**：让系统能装下比物理内存更多的数据；把长期不用的页换出，腾出内存给更需要的程序。
- **代价**：磁盘比内存慢得多。如果系统不断地换入换出，大量时间花在读写磁盘上，整体会变得很卡，这种现象常叫“颠簸”。

## 示例
```bash
# 查看内存和 swap 的使用情况
free -h

# 查看当前启用的 swap 设备或文件
swapon --show
```

## 易错点
- 以为 swap 能完全代替内存；它比内存慢得多，只是应急的后备
- 以为用了 swap 就一定是出了问题；少量使用是正常的
- 以为 swap 一定是一个独立分区；也可以是文件

## 追问
### [f1] 内存很大，还需要 swap 吗？
不一定必须，但有 swap 可以把长期不用的页换出，把内存留给更有用的数据，也能在内存突然紧张时多一层缓冲。具体配置要看场景。
