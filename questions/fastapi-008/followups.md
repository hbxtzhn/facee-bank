## 追问 1：中间件与 yield 依赖谁先退出？

中间件入口先于路由依赖解析。退出时不能背固定顺序：`scope="function"` 的 yield 依赖在路由函数结束、响应发送前退出；默认请求作用域通常在响应发送后退出。流式响应的“取得响应对象”与“发送完 body”也是不同阶段。需同时说明 FastAPI 版本与依赖 scope。

## 追问 2：纯 ASGI 中间件为什么要放行非 HTTP scope？

同一应用可能收到 WebSocket 或 lifespan 事件。只处理 HTTP 时，应将其他 scope 原样委托下游，避免破坏握手或应用启动。每个请求的状态放在调用局部变量中，不把可变请求状态存在共享中间件实例上。
