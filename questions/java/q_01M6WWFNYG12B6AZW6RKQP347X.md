## 一句话
继承就是子类用 extends 直接拥有父类的属性和方法，形成「子类是父类的一种」的 is-a 关系，复用代码，子类还可以重写父类的方法。

## 要点
- [kp1|3] 子类用 extends 继承父类，自动拥有父类可访问的属性和方法
- [kp2|3] 继承表示 is-a 关系，如狗是动物
- [kp3|2] 子类可以重写（override）父类方法，提供自己的实现
- [kp4] Java 类只支持单继承，一个类只能有一个直接父类

## 详解
### 先搞懂：子女继承家业
做项目时，你可能有「普通用户」和「VIP 用户」，两者都有用户名、密码、登录方法。VIP 只是多了折扣。如果把相同的代码写两遍，改一处就得改两处。

继承就像子女继承家业：父类已经有的东西，子类直接用，不用重写；子类再添自己独有的东西。

后文要用的词：
- **父类 / 子类**：被继承的叫父类，继承它的叫子类。
- **重写**：子类写一个和父类同签名的方法，覆盖父类的实现。

### 怎么用：extends
子类在声明时写 `extends 父类`，就拥有了父类中非 private 的属性和方法。private 的成员虽然存在于对象里，但子类不能直接访问。

### is-a：什么时候该用继承
判断标准：能说「子类是一种父类」。狗是动物，VIP 用户是用户，可以继承。只是想借用某个功能，但两者不是 is-a，就不该继承，改用组合，即把对方作为一个成员变量来用。

### 重写：子类改写父类行为
父类的 `speak()` 输出「动物叫」，子类 `Dog` 可以重写成输出「汪汪」。重写是多态的基础。子类里可以用 `super` 调用父类的版本。

### 限制
- Java 只支持单继承，一个类只能有一个直接父类，但可以多层继承。
- 父类的构造方法不会被继承，但子类构造时会先调用父类构造。

## 示例
```java
class Animal {
    void speak() { System.out.println("动物叫"); }
}

class Dog extends Animal {
    @Override
    void speak() { System.out.println("汪汪"); }
}
```

## 易错点
- 为了复用几行代码就继承，但两者并不是 is-a，后期父类一改，所有子类都受影响
- 以为子类能直接访问父类的 private 属性；不能，只能通过父类提供的方法
- 以为 Java 可以多继承类；类只能单继承，多个能力用接口实现

## 追问
### [f1] 继承和组合怎么选？
是 is-a 关系且希望多态时用继承；只是想复用别的类的功能，优先用组合，耦合更低。

### [f2] 子类创建对象时，父类的构造方法会执行吗？
会。子类构造方法第一步总会先调用父类的构造方法，没有写 super(...) 时，默认调用父类无参构造。
