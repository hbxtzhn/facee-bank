## 一句话
IP 地址是分配给网络中主机的逻辑地址，数据包带着它，才能穿过多个网络送到目标主机。

## 要点
- [kp1|3] IP 地址给网络中的主机标识身份，用来定位目标
- [kp2|3] 每个 IP 数据包里都带着源地址和目的地址
- [kp3|2] 路由器根据目的地址，一站一站地转发数据包
- [kp4] IP 地址是逻辑地址，可以重新分配，和网卡硬件地址不同

## 详解
### 先搞懂：地址就是门牌号
你给外地朋友寄快递，必须写清楚收件地址，快递员才知道往哪送，沿途的中转站也靠这个地址决定下一站。

网络里发数据也一样。每台主机需要一个地址，数据包上写着“从哪来、到哪去”，沿途的设备才知道怎么转发。这个地址就是 IP 地址。几个词：

- **IP 地址**：分配给主机的逻辑地址，用来标识它在网络中的位置。
- **逻辑地址**：由网络配置分配，可以改变，不是网卡出厂时固定的。
- **数据包（IP 数据报）**：IP 层传输的一个数据单元，头部有源和目的地址。

### IP 地址做了什么
你访问一个网站，发出的每个数据包里，都有两个 IP 地址：

- **源地址**：你自己的地址，对方回复时往这里送；
- **目的地址**：要访问的服务器地址，沿途设备根据它转发。

数据包一般要跨过很多个网络，中间的路由器不需要认识最终的主机，只要根据目的地址，查路由表，把包交给下一站，一站一站送到目的主机。

### 为什么需要它
不同网络的底层设备五花八门，硬件地址的格式也不一样。有了统一的 IP 地址，就可以屏蔽这些差异，让数据包可以跨越多个网络，找到目的主机。

### 和 MAC 地址的区别
MAC 地址固化在网卡上，只在同一个局域网内用来找下一个设备。IP 地址是逻辑的，负责全程的“哪里是终点”。简单说：IP 地址管全程，MAC 地址管每一跳。

## 易错点
- 以为 IP 地址永远固定；它常由路由器或服务器动态分配，会变化
- 以为 IP 地址等于 MAC 地址；两者职责不同，一个定终点，一个管每一跳
- 以为路由器知道整条路径；它只负责决定下一站

## 追问
### [f1] 为什么有了 MAC 地址还需要 IP 地址？
MAC 地址是平的、没有网络位置信息，没法告诉路由器该往哪个方向走。IP 地址带网络位置，路由器才能按网络做转发。
