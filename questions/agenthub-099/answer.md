### 一句话总结

副本降低读取延迟，但应用要明确是否需要读到刚刚提交的版本。

### 回答要点

1. 先核对项目是否实际使用读复制和会话接口，不能仅凭 D1 产品支持就宣称当前请求都读取副本。

2. 需要顺序一致的交互可按官方 Sessions API 与 bookmark 机制设计会话衔接；数据库会话与网页用户登录会话不是同一概念。

3. 对安全或配置决策避免使用无法证明新鲜的缓存，记录版本辅助判断。使用何种一致性需求取决于业务而非一律强制主库。

### 常见误区与边界

这是平台扩展知识题，不代表该项目已经启用全球读副本。

### 资料核对

[Cloudflare：D1 Read Replication](https://developers.cloudflare.com/d1/best-practices/read-replication/)。官方资料用于核对通用 API 语义，不证明任何项目已启用相应能力。
