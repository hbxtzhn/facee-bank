## 一句话
并发是在一段时间内，多个任务交替推进；单核 CPU 靠时间片轮转，让它们看起来像是同时在运行。

## 要点
- [kp1|3] 并发指一段时间内多个任务都在被处理
- [kp2|3] 某一时刻，单核 CPU 上只有一个任务在执行
- [kp3|2] 单核靠时间片轮转实现并发，切换很快所以看起来同时
- [kp4] 并发是宏观上同时，微观上交替

## 详解
### 先搞懂：一个人同时做几件事
你一边烧水一边洗菜，水烧开前去洗一会儿菜，水开了回来关火。你并不是同时用两只手做两件事，而是在两件事之间来回切换，但整个过程中两件事都在推进。这就是并发。

后文要用的术语：

- **时间片**：操作系统分给每个任务的一小段 CPU 使用时间。
- **轮转**：这段时间用完，就换下一个任务，轮流使用 CPU。

### 单核 CPU 怎么做到并发
假设只有一个 CPU 核，运行着进程 A 和进程 B：

1. A 先运行一个时间片；
2. 时间片用完，操作系统把 CPU 切给 B；
3. B 运行一个时间片后，再切回 A，如此反复。

每个时间片都很短，切换速度又很快，所以从人的角度看，A 和 B 好像同时在运行。但任何一个瞬间，CPU 上只有一个任务。

### 并发是目的，时间片是手段
并发解决的问题是：不让一个程序一直独占 CPU。比如程序 A 在等待读硬盘，CPU 就可以先去执行 B，CPU 不会闲着，用户也不会觉得电脑卡死。

多核 CPU 上同样有并发：任务数通常比核数多，每个核上仍然是轮流运行多个任务。

## 易错点
- 以为并发就是同时执行；并发强调的是一段时间内交替推进
- 以为只有多核才能并发；单核靠时间片轮转也能并发

## 追问
### [f1] 并发和并行的区别是什么？
并发是一段时间内交替处理多个任务；并行是同一时刻真正有多个任务在执行，需要多核支持。
