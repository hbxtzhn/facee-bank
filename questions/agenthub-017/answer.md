### 一句话总结

定时器只安排最早可执行的回调，事件循环被占用时实际执行会延后。

### 回答要点

1. 同步大文件解析、复杂正则或大量 JSON 处理可能阻塞事件循环。模型网络等待与本地 CPU 阻塞要分别诊断。

2. 预算应保存绝对截止时间，每次关键操作前重新计算剩余量；定时回调负责发出取消信号，不能成为唯一防线。

3. 对 CPU 密集处理采用有界输入、分块或合适的工作线程方案，并验证目标运行时支持情况；不要在 Worker 中直接假设 Node 线程接口可用。

### 常见误区与边界

定时器精度、网络超时和业务截止时间不是同一概念。
