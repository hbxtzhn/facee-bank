## 一句话
TCP/IP 四层从上到下是应用层、传输层、网际层、网络接口层，分别管应用协议、端到端传输、选路寻址和相邻设备间的传输。

## 要点
- [kp1|3] 四层从上到下：应用层、传输层、网际层、网络接口层
- [kp2|3] 应用层放 HTTP 等协议，传输层放 TCP 和 UDP，网际层放 IP
- [kp3|2] 网络接口层负责帧的传输，用 MAC 地址在同一网络内找到设备
- [kp4] 传输层靠端口找到程序，网际层靠 IP 地址找到主机

## 详解
### 先搞懂：寄快递的几个环节
寄快递时，你写好寄件内容，快递公司按地址选路线，再由一段段车辆运送。TCP/IP 把这个过程拆成四层，每一层解决一个问题。

后文的术语：

- **协议**：通信双方约定好的规则，比如 HTTP、TCP、IP。
- **端口**：标识主机上的哪个程序。
- **IP 地址**：标识网络中的哪台主机。
- **MAC 地址**：标识同一局域网里的哪块网卡。

### 应用层：程序之间怎么说话
应用层包含各种面向具体应用的协议。浏览器和服务器用 HTTP，传文件用 FTP，发邮件用 SMTP。这一层决定数据的内容和格式。

### 传输层：端到端的传输
传输层负责让两台主机上的程序互相通信，用端口区分程序。它主要有两个协议：

- **TCP**：先建立连接，保证数据按顺序、可靠到达，丢了会重传，还有流量控制。
- **UDP**：不建立连接，直接发送，不保证可靠，但开销小。

### 网际层：选路和寻址
网际层主要的协议是 IP。它给每台主机一个 IP 地址，数据包要跨越多个网络时，由路由器根据 IP 地址一跳一跳地转发，这就是路由。

### 网络接口层：在相邻设备之间传输
网络接口层负责把数据真正发到链路上。它把数据封装成帧，用 MAC 地址找到同一网络里的下一个设备，并做基本的错误检测。有线、无线这些具体的传输方式，都属于这一层。

### 四层的对应关系
数据发送时，每一层给上一层交下来的数据加上自己的首部：应用数据加上 TCP 首部，再加 IP 首部，最后加帧头。

## 易错点
- 以为 TCP/IP 只有 TCP 和 IP 两个协议；它是一整套协议的统称
- 把端口当成 IP 的一部分；端口属于传输层，IP 地址属于网际层
- 以为 MAC 地址能用来跨网络寻址；MAC 只在同一个局域网内有效

## 追问
### [f1] TCP/IP 四层和 OSI 七层怎么对应？
应用层对应 OSI 的应用、表示、会话三层；传输层对应传输层；网际层对应网络层；网络接口层对应数据链路层和物理层。
