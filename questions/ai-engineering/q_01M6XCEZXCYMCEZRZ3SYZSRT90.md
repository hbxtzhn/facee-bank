## 一句话
预训练就是在海量没有人工标注的文本上，让模型反复预测下一个 token，从中学到通用的语言知识。

## 要点
- [kp1|3] 预训练用海量无标注文本，不需要人工给答案
- [kp2|3] 训练目标通常是根据前文预测下一个 token
- [kp3|2] 预训练出的模型有通用语言能力，但不一定会听指令
- [kp4] 预训练成本很高，所以后续多在它的基础上微调

## 详解
### 先搞懂：像一个读了很多书的人
你用手机输入法时，打了「今天天气」，它会推荐「真好」。输入法是靠大量文字学会这种接话能力的。

预训练就是把这件事做到极致：让模型读几乎整个互联网规模的文字，每读一段，就练习猜下一个词是什么。猜得多了，它自然学会语法、常识，也积累了不少知识。

后文用到的术语：
- **token**：模型处理文本的最小单位，可能是一个字、一个词或词的一部分。
- **无标注**：文本本身就是训练材料，不需要人再写标准答案。
- **基座模型**：只做完预训练、还没经过后续训练的模型。

### 预训练怎么做：猜下一个 token
训练数据是一段普通文本，比如「今天天气很好」。模型每次看到前面的部分，去预测下一个 token：

1. 看到「今天」，预测「天气」；
2. 看到「今天天气」，预测「很」；
3. 把预测结果和真实文本对比，算出误差，再调整参数。

答案就藏在文本里，所以不需要人工标注。这种做法常被称为自监督学习，素材里说的「无监督」是比较宽泛的叫法。

### 预训练之后得到了什么
得到的是一个有通用语言能力的基座模型。它会续写、会补全，但你问它问题，它可能不是回答，而是接着再写几个问题。

要让它变成好用的助手，还需要微调和对齐。所以预训练是第一步，打基础；后面的训练是让它学会听话。

## 示例
```python
# 预训练的核心思想：输入是前文，标签是向后错一位的文本
tokens = ["今天", "天气", "很", "好"]
inputs = tokens[:-1]    # 今天 天气 很
labels = tokens[1:]     # 天气 很 好
```

## 易错点
- 以为预训练需要人工标注；文本本身就提供了答案，不需要人写
- 以为预训练完的模型就是聊天助手；它还需要微调和对齐才会遵循指令

## 追问
### [f1] 预训练和微调的区别是什么？
预训练用海量无标注数据学通用能力，成本高；微调用少量标注数据让模型适配具体任务或风格，成本低得多。

### [f2] 预训练的目标一定是预测下一个 token 吗？
不一定。GPT 这类自回归模型用预测下一个 token；BERT 类模型常用遮住某些词再猜。大语言模型主要采用前者。
