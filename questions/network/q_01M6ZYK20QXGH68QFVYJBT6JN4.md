## 一句话
NAT 是网关把内网私有地址换成公网地址的技术，让家里或公司里的多台设备共用一个公网 IP 上网。

## 要点
- [kp1|3] 私有地址只在内网有效，不能直接在互联网上路由
- [kp2|3] NAT 网关在数据出去时，把内网地址替换成自己的公网地址
- [kp3|2] 多设备共用一个公网 IP 时，靠端口区分各自的连接
- [kp4] NAT 网关用一张映射表记录对应关系，回包时据此转回

## 详解
### 先搞懂：公司总机和分机
一家公司有一个对外的总机号码，内部有很多分机。员工用分机打外线时，对方看到的是总机号。对方回电时，打到总机，由前台转给对应的分机。

NAT 就像这个前台：

- **内网设备**：像各个分机，使用只在内部有效的地址。
- **公网 IP**：像对外的总机号码，整个公司共用一个。
- **NAT 网关**（常见的就是家里的路由器）：负责对外替换地址、回来时转给对应设备。

后文的术语：

- **私有地址**：专门留给内网使用的地址段，不同内网可以重复使用，不能直接在公网上通信。
- **公网地址**：在互联网上唯一、能被路由的地址。

### 为什么需要 NAT
公网 IP 地址的数量有限，不可能给每台设备都分一个。内网设备使用私有地址。只需要网关拥有一个公网地址，就能让大量设备上网，节省了公网地址。

### NAT 怎么工作：以访问网站为例
1. 内网电脑 A 发出请求，源地址是私有地址和一个端口。
2. 请求到达 NAT 网关。网关把源地址换成自己的公网 IP，把源端口也换成一个自己分配的端口。
3. 网关在映射表里记下「公网端口对应内网的 A 和它的端口」。
4. 服务器收到请求，看到的源地址是网关的公网 IP，于是把响应发回这个地址和端口。
5. 网关收到响应，查映射表，把目的地址换回 A 的私有地址，再转给 A。

多台设备同时上网时，网关给它们分配不同的端口。网关靠端口把各自的连接区分开。这种用到端口的做法叫 NAPT，也常被直接称作 NAT。

### NAT 带来的影响
- 好处：节省公网地址。外部看不到内网设备的真实地址，有一定的隐蔽作用。
- 限制：外部主动访问内网设备比较困难，因为映射表里没有对应的记录。
- 想让外部访问内网服务，需要在网关上配置端口映射，或使用内网穿透工具。

## 易错点
- 以为 NAT 是防火墙；它只做地址转换，客观上挡住了部分外部主动访问，但不是专门的安全机制
- 以为内网设备的 IP 在公网上也能用；私有地址不能被互联网直接路由
- 以为多设备共用 IP 时会冲突；网关靠不同端口区分各自的连接

## 追问
### [f1] 内网的服务器怎么让外网访问？
在 NAT 网关上做端口映射：把公网 IP 的某个端口固定映射到内网服务器的地址和端口。外部访问这个端口时，网关就转给内网服务器。
