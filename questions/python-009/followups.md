## 追问 1：在闭包内部如果要修改外层函数的变量，为什么必须使用 nonlocal 关键字？

在 Python 中，如果函数体内对一个变量执行赋值操作（如 count = count + 1），Python 编译器在解析字节码时会自动将 count 判定为当前函数的局部变量。如果不加 nonlocal，执行时就会在局部作用域找不到该变量而抛出 UnboundLocalError。

## 追问 2：闭包与纯类（Class）相比有什么优劣？何时优先用闭包？

闭包非常轻量，只有一个函数签名和 __closure__ 命名空间，在只有一两个方法或需要实现轻量级回调、装饰器、工厂函数时，写闭包代码比定义一个完整的类更简洁高效。
