## 一句话
类加载分为加载、验证、准备、解析、初始化五个阶段；完整的类生命周期在这之后还有使用和卸载。

## 要点
- [kp1|3] 类加载五阶段：加载、验证、准备、解析、初始化
- [kp2|2] 验证、准备、解析三个阶段合称"链接"
- [kp3|2] 完整生命周期还有使用和卸载，共七个阶段
- [kp4] 各阶段按顺序开始，但常常交叉进行，不是等上一个完全结束

## 详解
### 先搞懂：一个类从"文件"到"能用"要走几步
把类想成一个新员工：先报到入职（加载），再审核资料（验证），分配工位（准备），熟悉同事（解析），最后正式上岗（初始化）。上岗后开始工作（使用），离职后工位收回（卸载）。

后文用到的术语：
- **链接**：验证、准备、解析三步的合称。
- **生命周期**：一个类从被加载进内存到被卸载出内存的全过程。

### 五个阶段，各用一句话说
1. **加载**：找到 .class 文件，读入内存，生成 Class 对象。
2. **验证**：检查字节码是否合法、安全。
3. **准备**：给静态变量分配内存，赋默认值。
4. **解析**：把符号引用换成直接引用。
5. **初始化**：执行静态变量赋值和静态代码块。

### 之后还有两步
- **使用**：程序创建对象、调用方法，正常运行。
- **卸载**：类不再被使用，对应的 Class 对象被回收，类的信息从内存中清除。

### 顺序是什么意思
加载、验证、准备、初始化这几个阶段是按这个顺序开始的。但它们常常交叉进行：比如加载还没完全结束，验证就可能开始了。解析阶段有时会在初始化之后才发生，这样是为了支持 Java 的动态绑定。

## 易错点
- 把使用和卸载也算进"类加载过程"；类加载通常指前五个阶段
- 记错顺序，把解析放到准备之前；正确顺序是准备在解析之前
- 以为每个阶段都必须等上一个完全结束才开始

## 追问
### [f1] 什么是链接？
验证、准备、解析三个阶段合称链接，指把加载进来的类的数据整理成可以执行的状态。
