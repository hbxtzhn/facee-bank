## 一句话
管道是内核里的一段先进先出缓冲区，数据单向流动：一个进程往一端写，另一个进程从另一端读。

## 要点
- [kp1|3] 管道是内核中的一段缓冲区，不是磁盘文件
- [kp2|3] 数据单向流动，先写入的先被读出
- [kp3|2] 匿名管道只能用在有亲缘关系的进程之间，如父子进程
- [kp4|2] 命名管道有文件名，无亲缘关系的进程也能使用
- [kp5] 管道满了写入会等待，空了读取会等待

## 详解
### 先搞懂：一根单向的水管
想象一根水管：一头往里倒水，另一头接水。水只能朝一个方向流，先倒进去的先流出来。两个进程要传数据，就可以用这根水管：一个进程负责倒，一个负责接。

后文要用的术语：

- **缓冲区**：临时存放数据的一块内存。
- **FIFO**：先进先出，先写入的数据先被读出。
- **内核**：操作系统的核心部分，管道的缓冲区就在它管理的内存里。

### 管道怎么用
在命令行里，最常见的就是竖线：

- `ps aux | grep java`：前一个命令的输出，经过管道，变成后一个命令的输入。

程序里则通过系统调用创建管道，得到两个文件描述符：一个用来写，一个用来读。

### 两种管道
- **匿名管道**：没有名字，通常由父进程创建，再通过创建子进程传给子进程，所以主要用于父子或兄弟进程。
- **命名管道**：在文件系统里有一个名字，不相关的进程只要知道名字，就能打开它通信。

### 几个特点
- **单向**：一根管道只能一边写、一边读。要双向通信，需要两根；
- **容量有限**：管道满了，写入的进程会等待；空了，读取的进程会等待；
- **不是持久存储**：数据读走就没了，也不会保存到磁盘。

## 示例
```bash
# 前一个命令的输出，通过管道交给后一个命令
ps aux | grep java
```

## 易错点
- 以为管道可以双向通信；一根管道只能单向，双向要用两根
- 以为匿名管道可以在任意两个进程间使用；它需要靠继承才能传给对方

## 追问
### [f1] 管道和消息队列有什么区别？
管道是无格式的字节流，先进先出；消息队列里是一条条带类型的消息，读取方可以按类型取。
