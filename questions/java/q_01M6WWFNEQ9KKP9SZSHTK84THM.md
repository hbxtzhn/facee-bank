## 一句话
引用类型包括类、接口、数组，这类变量里保存的是对象的地址（引用），对象本身放在堆里，所以把变量赋给另一个变量，两个变量指向的是同一个对象。

## 要点
- [kp1|3] 引用类型有类、接口、数组三种，变量保存的是指向对象的引用
- [kp2|3] 对象本身存放在堆中，引用变量只是指向它
- [kp3|2] 赋值或传参复制的是引用，两个变量指向同一个对象，改一个另一个也能看到
- [kp4] 引用可以是 null，表示没有指向任何对象，通过它调用方法会抛空指针异常

## 详解
### 先搞懂：快递单号和包裹
引用类型的变量，就像一张快递单号：单号本身很小，真正的包裹（对象）放在仓库里。你把单号抄给另一个人，两个人拿着的单号对应的还是同一个包裹。

做项目时你一定遇到过：把一个 `User` 传给方法，方法里改了名字，外面的 `User` 也变了。原因就是传过去的是单号，包裹没有复制。

后文要用的词：
- **堆**：JVM 里存放对象的内存区域。
- **引用**：指向对象的地址信息，变量里存的就是它。
- **null**：空引用，表示没有指向任何对象。

### 哪些是引用类型
除了 8 种基本类型，其他都是引用类型：
- **类**：如 `String`、`User`；
- **接口**：如 `List`；
- **数组**：如 `int[]`，数组本身也是对象。

### 变量和对象是分开的
`User u = new User();` 做了两件事：在堆里创建一个 `User` 对象；让变量 `u` 保存指向它的引用。对象和变量是两个独立的东西。

### 赋值和传参：复制的是引用
`User v = u;` 之后，`u` 和 `v` 指向同一个对象。通过 `v` 改属性，`u` 看到的也是改后的值。方法传参同理：传的是引用的副本，方法内部通过它改对象属性，外面能看到。但在方法里让参数指向别的新对象，外面的变量不会变。

## 示例
```java
User u = new User("张三");
User v = u;          // 复制引用，不复制对象
v.setName("李四");
System.out.println(u.getName());  // 李四
u = null;            // u 不再指向对象，v 还指着
```

## 易错点
- 以为 `v = u` 会复制出一个新对象；其实只是多了一个指向同一对象的引用
- 以为方法传参是「引用传递」；Java 只有值传递，传的是引用的副本
- 对值为 null 的引用调用方法，会抛 `NullPointerException`

## 追问
### [f1] == 比较引用类型比较的是什么？
比较的是两个引用是否指向同一个对象，不是内容是否相同。内容比较要用 equals，前提是类重写了 equals。

### [f2] 局部变量的引用放在哪，对象放在哪？
局部变量（含引用）放在栈帧里，对象放在堆里。
