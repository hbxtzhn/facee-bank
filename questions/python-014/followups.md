## 追问 1：为什么在 Python 代码中检查变量是否为 None 时，强烈规定必须写 if x is None 而不是 if x == None？

因为 None 在 Python 全局是唯一的单例对象。is 比较的是底层指针地址，仅需一条汇编指令比较，耗时极短；而 == 会触发调用对象的 __eq__() 方法，如果被测对象重写了 __eq__ 并返回了非预期的布尔值（例如某些数据框架重写了相等比较），== None 会产生误判或性能损耗。

## 追问 2：为什么 a = 257; b = 257 在交互式终端（REPL）逐行执行时 a is b 为 False，而在脚本文件中执行为 True？

在脚本中整段代码会作为同一个代码块（Code Object）一起被编译器编译，触发了「常量折叠（Code Block Interning）」优化，相同的字面量常量会被合并为一个对象；而在命令行 REPL 中每一行都是单独编译的，不会跨行共享对象池。
