## 一句话
强化学习是让智能体在环境里不断试错，根据得到的奖励调整行为策略，目标是让长期累计的奖励最大。

## 要点
- [kp1|3] 核心角色是智能体和环境：智能体做动作，环境返回状态和奖励
- [kp2|3] 没有标准答案，只有奖励信号告诉它做得好不好
- [kp3|2] 目标是长期累计奖励最大，而不是眼前这一步的奖励
- [kp4] 智能体靠不断试错来改进策略，策略就是遇到什么状态做什么动作

## 详解
### 先搞懂：像训练小狗
训小狗坐下：它做对了就给零食，做错了没有零食。你不会告诉它「坐下的正确姿势是什么」，它自己试来试去，慢慢发现某些动作能换来零食，就越来越常做这些动作。

强化学习就是这个过程的数学化。再比如玩游戏，没人教你每一步该怎么走，你只看最后的分数，多玩几局就摸出门道了。

后文用到的术语：
- **智能体**：做决策的一方，如游戏角色或机器人。
- **环境**：智能体所处的世界，会对动作做出反馈。
- **奖励**：环境给的分数，正的是鼓励，负的是惩罚。
- **策略**：在某个状态下选哪个动作的规则。

### 一个回合怎么走
循环是这样的：

1. 智能体观察当前状态；
2. 按策略选一个动作；
3. 环境返回新的状态和一个奖励；
4. 智能体根据奖励更新策略，再进入下一轮。

### 为什么强调长期累计奖励
有些动作眼前没有奖励，甚至要吃点亏，但后面会得到大回报，比如下棋时牺牲一个子换取全局优势。如果只看眼前奖励，智能体学不会这种远见。

所以强化学习优化的是累计奖励，通常还会对越遥远的奖励打个折扣。

### 和监督学习的区别
| 对比点 | 监督学习 | 强化学习 |
|---|---|---|
| 反馈 | 每条数据都有标准答案 | 只有奖励信号，常常有延迟 |
| 数据来源 | 事先准备好的数据集 | 智能体自己与环境交互产生 |
| 学什么 | 输入到输出的映射 | 一套让回报最大的行为策略 |

结论：有大量标准答案时用监督学习；只能评判结果好坏、需要探索时才用强化学习。

## 示例
```python
state = env.reset()
done = False
while not done:
    action = policy(state)                       # 按策略选动作
    state, reward, done = env.step(action)       # 环境给出新状态和奖励
    agent.learn(reward)                          # 根据奖励更新策略
```

## 易错点
- 以为强化学习需要标准答案；它只依赖奖励，答案是自己试出来的
- 以为每一步都追求最高奖励；目标是整个过程的累计奖励
- 以为奖励随便设就行；奖励设计不当，智能体会钻空子，得高分却没做对事

## 追问
### [f1] 强化学习和大模型有什么关系？
大模型用它做对齐，比如 RLHF：把模型回答当作动作，把人类偏好训练出的奖励模型打分当作奖励，再优化模型。

### [f2] 什么是探索和利用？
利用是继续选已知最好的动作，探索是尝试没试过的动作。只利用会错过更好的做法，只探索又拿不到稳定回报，需要在两者之间平衡。
