## 一句话
多态就是用父类引用调用同名方法时，具体执行哪个子类的实现，由运行时对象的真实类型决定，同一个调用在不同对象上有不同表现。

## 要点
- [kp1|3] 父类引用指向子类对象，调用的是对象真实类型的重写方法
- [kp2|3] 执行哪个版本在运行时才确定，这叫动态绑定
- [kp3|2] 多态需要继承、重写、父类引用指向子类对象三个条件
- [kp4] 多态让调用方不依赖具体子类，新增子类不用改调用处

## 详解
### 先搞懂：同一句「付款」，不同的结果
做项目时你会遇到「支付」：用户可以选微信、支付宝、银行卡。调用方只管喊一句「付款」，具体怎么付，看用户选的是哪种。

类比一下：你对一群人喊「开始跳舞」，每个人跳的舞不一样。喊话的方式相同，各人有各人的做法。

后文要用的词：
- **父类引用**：用父类类型声明的变量，如 `Animal a`。
- **重写**：子类对父类方法给出自己的实现。
- **动态绑定**：运行时才确定调用哪个方法版本。

### 多态是怎么发生的
```java
Animal a = new Dog();
a.speak();
```
变量 `a` 的类型是 `Animal`，但它指向的对象是 `Dog`。调用 `speak()` 时，JVM 看的是对象的真实类型，于是执行 `Dog` 重写后的版本。把 `new Dog()` 换成 `new Cat()`，同一行 `a.speak()` 就变成猫的叫声。

### 为什么有用
调用方只和父类打交道，不需要写一堆 `if (是狗) … else if (是猫) …`。新增一种动物，只要新写一个子类，调用的代码不用动。

### 要注意的边界
- 多态只针对**方法**；属性不具备多态，用父类引用访问的是父类的属性。
- 父类引用只能调用父类里声明过的方法，子类独有的方法要先强制转换。
- `static`、`private`、`final` 方法不能被重写，也就没有多态。

## 示例
```java
Animal a = new Dog();
a.speak();   // 汪汪，执行的是 Dog 的版本
a = new Cat();
a.speak();   // 喵喵，同一行代码，结果不同
```

## 易错点
- 以为方法执行哪个版本看变量的声明类型；其实看对象的真实类型
- 以为成员变量也有多态；变量看声明类型
- 说「重载是多态」；重载在编译期就确定了，一般说多态指重写带来的运行时多态

## 追问
### [f1] 多态的三个条件是什么？
要有继承关系，子类重写了父类方法，并且用父类引用指向子类对象。

### [f2] 多态底层靠什么实现？
靠运行时按对象真实类型查找方法，JVM 通常通过方法表（虚方法表）来实现。
