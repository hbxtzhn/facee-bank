## 一句话
数据报比链路的 MTU 大时，路由器会把它切成几片，每片带上标识和偏移量，最后由目的主机拼回完整数据报。

## 要点
- [kp1|3] 链路有最大传输单元 MTU，超过的数据报要分片
- [kp2|3] 同一数据报的各片共用标识，用偏移量标明位置
- [kp3|2] 分片可以发生在途中的路由器，重组只在目的主机
- [kp4|2] 任何一片丢了，整个数据报都无法重组
- [kp5] 以太网的常见 MTU 是 1500 字节

## 详解
### 先搞懂：大箱子塞不进小门
你要寄一件大家具，快递中转站的门太小，搬不进去，只好拆成几块，每块贴上同一个订单号，并写“这是第几块”。收货人收齐后，按编号重新拼起来。

IP 分片就是这样。几个词：

- **MTU**：一条链路一次最多能传的数据大小。
- **分片**：把一个超过 MTU 的数据报拆成若干个小数据报。
- **重组**：把分片拼回原来的数据报。

### 分片是怎么做的
数据报穿过不同的网络，每段链路的 MTU 可能不同，例如以太网常见 MTU 是 1500 字节。

1. 路由器发现数据报比出口链路的 MTU 大，就把它切成几片；
2. 每一片都有自己的 IP 头，其中的**标识**字段相同，表示它们来自同一个数据报；
3. 头里的**偏移量**说明这一片在原数据中的位置，以 8 字节为单位；
4. 头里的**更多分片标志**说明后面还有没有分片，最后一片这个标志为 0。

### 重组在哪里做
重组只在目的主机，中途的路由器不会重组。因为各片可能走不同的路径，路由器未必能收齐。目的主机收到后，按标识把属于同一数据报的分片归在一起，再按偏移量排序，拼成原数据报，交给上层。

### 分片有什么代价
- 一片丢了，整个数据报只能作废，上层要整个重传，所以丢包的影响被放大；
- 路由器和目的主机都要多做工作。

所以实际中，常常希望一开始就把数据包切到合适的大小，尽量避免 IP 层分片。

### 进阶：不让分片（基础薄弱可先跳过）
IP 头里还有一个“不分片”标志。设置它后，如果数据报超过 MTU，路由器不分片，而是丢掉它，并发 ICMP 消息告诉发送方。发送方据此探测路径上的最小 MTU。IPv6 里路由器不再分片，由发送方自己决定数据包大小。

## 易错点
- 以为路由器会重组分片；重组只在目的主机
- 以为偏移量以字节为单位；它以 8 字节为单位
- 以为分片丢了一片没有影响；整个数据报都会无法重组

## 追问
### [f1] 为什么要尽量避免 IP 分片？
任何一片丢失，整个数据报都要重传，而且分片、重组都耗资源。TCP 通常会控制报文段大小，避免这种情况。

### [f2] 分片的各片可能乱序到达吗？
可以。各片可能走不同路径，所以目的主机要靠标识和偏移量，才能把它们重新拼对。
